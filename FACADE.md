# QueueFlow Python facade

The facade documentation has moved into [README.md](./README.md), which is the single entry point
for this package: install, quick start, the `QueueFlow` client, the `wf()` workflow builder,
`run_worker`, authentication, error handling, and the conformance tests.

`queueflow/facade.py` is injected at generation time from the queueflow-core template
(`sdk-templates/python/facade.mustache`); edit the template, not the file.
